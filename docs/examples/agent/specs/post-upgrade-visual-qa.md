# Post-Upgrade Visual QA

This is a reusable procedure. Product-specific requirements and blockers belong in the task manifest.

## Rounds

1. Homepage desktop at 1440x900 and 1280x800: proposition, hierarchy, pacing, text density, premium restraint, and template cues.
2. Selector desktop: entry points, search, machine selection, goals, matching, bundle expansion/removal, and variant text.
3. Selector mobile at 390x844 and 430x932: sheet behavior, safe area, sticky state, keyboard, list scroll, overflow, and hidden content.
4. PDP: selected machine, unsupported state, unverified state, and truthful UI updates.
5. Cart: intentional prelaunch limitations, no fabricated evidence, and no unexpected provider request.
6. Comparative review against the evidence named by the task manifest.

## Output

Report acceptance criteria, observed behavior, blocked/unknown states, evidence paths, concrete defects, and one highest-leverage improvement. Use qualitative visual ratings or a coarse 1-5 scale. Do not use unsupported decimal precision.

## Generic Browser Checks

Apply: `visual-browser-qa` skill.
